Proyecto Web Scraping

Extracción y análisis de información de libros con Python

Descripción del proyecto

Este proyecto académico utiliza técnicas de Web Scraping para recopilar información de libros disponibles en una página web de práctica.

Objetivo

Extraer y organizar datos como títulos, precios, disponibilidad y enlaces de los libros.

Herramientas utilizadas

  • Python
  • BeautifulSoup
  • Selenium
  • Scrapy
  • Pandas
  • Git y GitHub
  • GitHub Actions

Fuente de información

Books to Scrape

Integración y despliegue continuo
