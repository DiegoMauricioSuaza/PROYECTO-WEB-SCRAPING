Acerca del proyecto

Este proyecto consiste en obtener información de libros desde el sitio web Books to Scrape. Se recopilan datos como títulos, precios, disponibilidad y enlaces de los productos.

La información se procesa utilizando Python y sus herramientas de extracción y análisis de datos. Además, se implementa un proceso CI/CD para automatizar las pruebas y la publicación de esta página web.

Visitar Books to Scrape

Objetivos

  • Extraer información de libros desde una página web.
  • Aplicar técnicas de Web Scraping con Python.
  • Organizar los datos obtenidos para facilitar su análisis.
  • Gestionar el código fuente mediante Git y GitHub.
  • Automatizar pruebas y despliegues utilizando GitHub Actions.

Herramientas utilizadas

Python

Lenguaje utilizado para desarrollar la extracción de datos.

BeautifulSoup

Permite analizar HTML y extraer información de las páginas.

Selenium y Scrapy

Herramientas para automatizar la navegación y el scraping.

Pandas

Permite organizar y procesar los datos recopilados.

Git y GitHub

Control de versiones y almacenamiento del proyecto.

GitHub Actions

Automatización de pruebas y publicación de la aplicación.

Proceso de integración y despliegue continuo

El proyecto utiliza un pipeline CI/CD mediante GitHub Actions. Cuando se realizan cambios en la rama principal, se instalan las dependencias y se ejecutan pruebas automáticas con pytest. Si las pruebas son exitosas, se publica la página en GitHub Pages.
